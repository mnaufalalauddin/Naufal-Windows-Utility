# Naufal Windows Utility v8.0.0.0 — GPU Driver & Header Preview

8 October 2026 · **Development pre-release** · Windows 10 / 11 x64 targets

## What's new

- GPU Driver Manager groups **Check for updates**, **Repair driver** and
  **Download & install** in one fixed, responsive header.
- NVIDIA installed versions use the public format, such as **617.14**, instead
  of the Windows INF form `32.0.16.1714`.
- Choose verified driver types for the selected GPU/OS: NVIDIA Game Ready / Studio,
  workstation RTX Enterprise, supported AMD Recommended / Optional packages, and
  Intel Graphics / Arc Pro where the catalog confirms support.
- The release panel displays version, date, official source and release time
  only when supplied by the vendor. Missing hours are not invented. Checking
  metadata never installs or downloads a driver package automatically.
- Install and Repair confirm and revalidate the selected channel/release. Repair
  can update or switch the driver type; it is not necessarily same-version repair.
  No silent substitute-channel fallback or automatic downgrade is offered.
- About / Task Monitoring / Exit stay within the viewport on all sidebar pages.
- README now has clearer navigation, refreshed feature documentation and labelled
  GPU header previews, alongside the existing Home Light/Dark screenshots.

## Verification and limitations

Fresh Native AOT / Inno Setup packaging passes. Regression checks cover 151 GPU
metadata/service assertions, 4,786 profile/action assertions, 347 English UI
checks, 92 routing checks, 33 identity checks, 27 simplified-interface checks and
91 icon checks. The implementation's native UI suite passes 41,521 assertions,
including 12 GPU-header/panel combinations in Light/Dark at 25/100/200% text scale.

Read-only NVIDIA catalogs were checked on the development RTX 4070 Ti SUPER;
additional AMD/workstation cases use synthetic identities. Intel currently returns
HTTP 403 on the development PC; Intel parsing is fixture-tested, not live-certified.
Unsupported/OEM GPUs may require the manufacturer's manual driver workflow.
**No real driver installation or repair was performed in these tests.** Neither
test counts nor a successful build establish universal hardware compatibility.

HVCI remains read-only; previously removed storage/offline/resource modules are
not reintroduced. Existing tweak, repair, SMART and recovery features are retained.
This preview does not replace earlier release history or claim a stable milestone.
