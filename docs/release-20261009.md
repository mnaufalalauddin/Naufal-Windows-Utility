# Naufal Windows Utility v8.0.0.0 — Intel Catalog Fix Preview

9 October 2026 · **Development pre-release** · Windows 10 / 11 x64 targets

## Fixed

- Intel catalog requests now explicitly request HTML and English content. The
  same URL/client reproduced HTTP 403 without these headers and 200 with them
  on the development connection. No browser cookies, login session, credentials,
  UA impersonation or third-party proxy is used.
- Live metadata probes successfully read Arc, Arc Pro, UHD 630 and Iris Xe
  catalog versions, release dates and approved direct-package URLs. Unsupported
  Arc/Pro choices remain excluded. Latest versions are not hardcoded.
- Failed HTTP responses are disposed before their errors propagate.
- README has a refreshed release banner, download links, preview overview and
  validation notes. Existing Home Light/Dark screenshots and labelled native
  GPU component previews remain available.

## Retained from the previous preview

Check for updates, Repair driver and Download & install share one GPU header.
Driver-type choices follow the selected GPU/OS. NVIDIA versions use public
formatting such as 617.14. Main-window About / Task Monitoring / Exit remain
within the viewport. Existing repair, tweak, SMART and recovery features remain.
No automatic installation is triggered by an update check.

## Verification and limits

Fresh Native AOT / Inno Setup packaging passes without compiler warnings. Checks
pass: 163 GPU metadata/service assertions, 4,786 profile/action assertions,
347 English UI checks, 33 identity checks, 92 routing checks and 91 icon checks.

Intel catalog probes use synthetic device identities and retrieve metadata only.
**No driver package was downloaded or installed during these tests.** Successful
catalog access does not certify real hardware installation or every CDN/network
route. A future rejection remains an explicit unavailable result, with the manual
official source link retained. Binary-download and other-vendor request headers
are unchanged. OEM/customized devices can still require the manufacturer's driver.

Earlier releases remain intact. This preview does not claim a stable milestone.
